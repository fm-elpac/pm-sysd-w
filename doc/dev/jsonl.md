# IPC 协议 (jsonl 模块)

`jsonl` 模块负责 init 与 ctl / log 之间的 JSONL 通信协议. 本模块只做消息编解码
(协议处理), 不做 IO (消息收发与限制由 `pa` 模块负责).

## 传输

- Linux: 当前目录的 UNIX socket (仅用于测试).
- Windows: 命名管道, 需要权限控制, 只允许本机连接.

## 协议

- 数据传输基于 JSONL (单行 JSON), 使用 `serde_json` 编解码.
- 连接后先做版本握手 (传输协议版本 + 软件版本), 之后的消息无需版本号.
- 后续请求为两层结构: 外层指定处理组件与是否只读, 内层指定具体操作.

握手消息格式, 各请求 / 响应类型与字段, 见 `jsonl` 模块的代码注释.

传输协议属于内部 API, 不作为外部稳定 API 提供, 小版本也可能引入 BREAKING change.
原则上 init 与 ctl / log 的版本应一致.
