# 内存目标与防御限制

## 内存目标

pm-sysd-init 的内存目标: 在适当配置下, 运行时内存 (含所有防御上限) 不超过 100MB.
即在可用内存只有 100MB 时, pm-sysd-init 能正常运行, 不崩溃. 为此,
代码中引入各种防御限制.

## 防御限制

防御限制覆盖配置解析 (配置文件 / unit 大小), IPC (消息大小, 超时, 并发连接),
配置重载 (软 / 硬超时), 日志 (单条长度, 分页条数, 保留时长, 限速警告), 数据库
(通道缓冲) 等.

具体限制以 `SYSD_LIMIT_` 前缀的常量定义在 `src/conf/limit.rs` (唯一例外:
`SYSD_CONF_LIMIT_TOTAL_BYTE`), 取值与行为见代码注释.
