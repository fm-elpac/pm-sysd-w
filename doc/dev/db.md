# 数据库 (db 模块)

pm-sysd-init 使用 sqlite 数据库存储持久状态 (unit 的 enable / mask) 与日志.
数据库格式属于内部 API, 不作为外部稳定 API 提供. 文件位置与配置见用户文档.

日志写入由日志批发线程与日志写入线程协作完成, 详见 [log.md](log.md) 与 `db`
模块的代码注释.

## 日志表索引与写入优化

`[env] SYSD_DB_LOG_NO_INDEX = "1"` 时, 新建数据库的日志表不创建索引.
此模式面向大量小日志的纯追加写入, 牺牲日志查询性能以降低写入开销.
仅影响新建数据库, 已存在的数据库不改变.

## schema 版本与升级

数据库必须存有 schema 版本号, 用于版本检测与自动升级:

- 版本检查, 初始化, 升级封装在单个事务中, 失败整体回滚.
- 仅允许向前升级, 遇到更新版本的数据库报错退出.
- 在 v0.1.0 发布之前 (覆盖所有 `0.1.0-*` 预发布版本) schema 版本保持 1 不变.
  之后每次变更递增版本号并补充迁移代码.

具体表结构, 升级流程, 线程模型与事务约定, 见 `db` 模块的代码注释.
